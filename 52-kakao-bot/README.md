# 카톡 단톡방 AI 비서 봇

아론AI 52편에서 우리 집 단톡방에 넣어 쓴 봇입니다. 단톡방에서 봇을 멘션하면 클로드가 답하고,
장보기 목록을 기억하고, 정한 시각에 먼저 알림을 보냅니다.

> ⚠ 카카오가 허락한 방식이 아닙니다. 맥의 카카오톡 앱을 손쉬운 사용 기능으로 조작합니다.
> 계정이 제한될 수 있으니 **본계정이 아닌 따로 만든 계정**으로 하세요.

## 붙이기 전에 확인할 것

| | 확인할 것 | 우리가 겪은 것 (2026-11-13) |
|---|---|---|
| 1 | 공식 길이 있나 | 내 봇을 단톡방에 넣는 공식 길은 없었다. 공식 챗봇(카카오톡 채널 챗봇)은 1:1 뿐이고, 6월에 열린 단톡방 챗봇은 카카오가 붙인 것(챗GPT 등)만 고를 수 있다 |
| 2 | 봇 계정 | 따로 만든 카톡 계정 하나 + 늘 켜 둘 맥 한 대. 맥 카톡은 앱 하나에 계정 하나라 내 카톡과 같은 맥에서는 못 돌린다 |
| 3 | 오픈채팅방이면 | 본인인증 안 한 새 계정은 들어가기·읽기는 되고 **말하기만 막혔다**('이용자보호조치'). 도구는 '보냈다'고 찍었는데 실제로는 안 나갔다 — 받는 사람 화면에서 확인할 것 |
| 4 | 봇 이름 | 카톡은 친구 이름을 보는 사람 폰에 저장된 이름으로 보여 준다. 봇 이름을 바꿔도 가족 폰마다 따로 바꿔야 화면이 맞는다 |
| 5 | 무엇이 밖으로 나가나 | 멘션한 글 + 앞 대화 30줄이 클로드로 간다. 멘션 없는 글은 보내지 않는다 |
| 6 | 넣지 않을 방 | 돈·계좌·주민번호가 오가는 방, 아이 학교·병원 이야기가 많은 방, 회사 업무 방 |
| 7 | 속도 | 봇이 글을 본 뒤 답을 보내기까지 5~11초(클로드 2.5~8초). 화면을 읽는 방식이라 실제 기다림은 더 길다 |
| 8 | 돈 | 클로드 구독 안에서 돌리면 추가 0원. API 가격으로 치면 답 하나 0.0004~0.0011달러 |

## 쓸 만했던 일

- `@봇이름 이번 주 가족 일정 정리해 줘` — 위 대화에서 일정을 날짜순으로 모은다. 지난 날짜도 짚었다
- `@봇이름 우유랑 계란 장보기에 넣어 줘` / `@봇이름 장보기 목록 보여 줘` — 목록은 `상태.json` 에 남는다
- `@봇이름 2분 뒤에 우유 사 오라고 알려 줘` — 그 시각에 봇이 먼저 방에 말을 건다
- `@봇이름 냉장고에 두부랑 김치 있는데 저녁 뭐 해 먹지?`

## 설치

필요한 것: 맥 · 맥용 카카오톡(봇 계정으로 로그인) · [kmsg](https://github.com/channprj/kmsg) · 클로드 코드(로그인) 또는 Anthropic API 키

```bash
brew install channprj/tap/kmsg
kmsg status            # 손쉬운 사용 허용을 묻는다 — 시스템 설정에서 켠다
```

봇 계정에 단톡방을 하나 만들거나 초대받은 뒤, 그 방 창을 열어 둔 채로:

```bash
python3 bot.py "방 이름" --name 봇이름 --catch-up
```

- `--name` 은 방에 보이는 봇 이름(멘션 글자). 봇 계정 쪽에서 보이는 이름을 쓴다
- `--catch-up` 은 켤 때 밀린 멘션(뒤에 봇 답이 없는 것)에 먼저 답한다
- `--dry-run` 은 보내지 않고 답만 찍는다(처음 시험할 때)
- `ANTHROPIC_API_KEY` 가 있으면 API 로, 없으면 `claude -p` 로 부른다. 기본 모델은 haiku
- 기록은 `기록.jsonl`(답마다 걸린 초·값), 장보기·알림은 `상태.json`

## 우리가 막힌 곳

- **방 이름은 겹치지 않게** — kmsg 는 이름 일부만 맞아도 그 방을 찾는다. '아론AI' 를 읽으라 했더니 '아론AI 오픈채팅방' 을 읽었다. 봇은 다른 방을 읽으면 멈춘다
- **오래 띄운 방 창이 새 글을 그리지 않을 때가 있다** — 채팅 목록엔 새 글이 있는데 방 창엔 없었다. 봇이 목록의 마지막 글과 읽은 글을 대 보고 다르면 방 창을 다시 연다
- **방 창을 닫으면 kmsg 가 방을 못 찾을 수 있다** — 채팅 목록에서 방을 열어 두고 켠다
- 맥 카톡 대화 파일을 바로 읽는 kakaocli 는 최신 카톡에서 열쇠를 못 찾아 멈췄다([이슈 #14](https://github.com/silver-flight-group/kakaocli/issues/14)) — 그래서 화면을 읽는 kmsg 로 갔다
